# Portfolio

Static portfolio site with no build step or runtime dependencies.

## Publish with GitHub Pages

1. Push the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing the site, and choose **/(root)**.
4. Save and wait for GitHub Pages to publish the site.

`index.html` is the site entry point. Keep `styles.css`, `script.js`, `Portrait.png`, and the `certifications` folder alongside it. GitHub Pages paths are case-sensitive.

Before sharing the site, replace the placeholder email and LinkedIn details in `script.js`.
